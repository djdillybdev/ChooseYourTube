# Portfolio screenshots

These images use deterministic fake-backend data and generic fixture identities. Regenerate them
from `frontend/` after a shipping UI change:

```sh
pnpm portfolio:screenshots
```

The set covers login, Inbox, channel detail, open filters, follow-channel synchronization feedback,
Watch Later, and mobile navigation. The capture is intentionally based on selected channels and
does not include recommendation, trending, engagement, or Shorts surfaces.
