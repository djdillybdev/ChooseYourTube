# ChooseYourTube v1.0.0

ChooseYourTube is a self-hosted YouTube inbox for browsing selected channels without recommendation
or engagement feeds. Version 1.0.0 is the first stable release of the Docker application and its
restricted hosted demo.

- [Hosted demo](https://chooseyourtube-demo-tawny.vercel.app)
- [Project documentation](https://github.com/djdillybdev/ChooseYourTube#readme)
- Video walkthrough: `chooseyourtube-demo-v1.0.0.mp4`

## Highlights

- Categories, tags, favorite channels, Watch Later, and ordered playlists.
- PostgreSQL full-text search with watched, channel, tag, date, and duration filters.
- Google Takeout CSV and one-time Google OAuth subscription import.
- Durable import and synchronization jobs with progress, safe errors, bounded retries, and quota
  accounting.
- RSS-first refresh and an hourly Redis and arq scheduler in full mode.
- Rotating HTTP-only refresh sessions behind the SvelteKit and FastAPI boundary.
- WCAG 2.2 AA target, keyboard-operable interactions, and automated axe checks.

## Docker installation

```bash
git clone --branch v1.0.0 https://github.com/djdillybdev/ChooseYourTube.git
cd ChooseYourTube
YOUTUBE_API_KEY=your-key make quickstart
make health
```

Release images are built for Linux `amd64` and `arm64`:

- `ghcr.io/djdillybdev/chooseyourtube-backend:1.0.0`
- `ghcr.io/djdillybdev/chooseyourtube-frontend:1.0.0`

Before upgrading an existing installation, create a backup, pull the exact image version, apply
migrations, and verify readiness. The
[deployment guide](https://github.com/djdillybdev/ChooseYourTube/blob/v1.0.0/docs/deployment.md)
documents the full procedure.

## Hosted demo restrictions

The Vercel and Neon demo shares the Docker application's services, models, and migrations. Backend
policy disables registration, imports, channel changes, and manual YouTube refresh. The demo has no
Redis worker or API key. A daily job resets mutable state and attempts a bounded RSS update while
retaining the last stored data when feeds are unavailable.
