# ChooseYourTube v1.0.0

ChooseYourTube is a self-hostable, distraction-free YouTube inbox with a polished one-click hosted
demo. This first stable release focuses on intentional viewing, user-owned data and observable
synchronization rather than recommendations or engagement feeds.

- **Live demo:** https://chooseyourtube-demo-tawny.vercel.app
- **Two-minute walkthrough:** attached as `chooseyourtube-demo-v1.0.0.mp4`
- **Documentation:** https://github.com/djdillybdev/ChooseYourTube#readme

## Highlights

- Categories, tags, favorite channels, Watch Later and ordered playlists.
- Full-text search plus watched, channel, tag, date and duration filters.
- Google Takeout CSV and one-time Google OAuth subscription import.
- Durable sync/import jobs with progress, safe errors, bounded retries and quota accounting.
- RSS-first refresh and an hourly Redis/arq scheduler in full mode.
- SvelteKit/FastAPI auth boundary with rotating HTTP-only refresh sessions.
- WCAG 2.2 AA target, keyboard-first interactions and automated axe coverage.

## Install with Docker

```bash
git clone --branch v1.0.0 https://github.com/djdillybdev/ChooseYourTube.git
cd ChooseYourTube
YOUTUBE_API_KEY=your-key make quickstart
make health
```

Pinned images are published for `linux/amd64` and `linux/arm64`:

- `ghcr.io/djdillybdev/chooseyourtube-backend:1.0.0`
- `ghcr.io/djdillybdev/chooseyourtube-frontend:1.0.0`

For existing installations, take a backup, pull the exact image version, run migrations before the
new API and verify readiness. See the [deployment guide](https://github.com/djdillybdev/ChooseYourTube/blob/v1.0.0/docs/deployment.md).

## Hosted-demo boundaries

The Vercel/Neon demo shares the same code and migrations as the Docker application but deliberately
disables registration, imports, channel mutation and manual YouTube refresh. It has no Redis worker or
API key; a daily cron resets mutable state and attempts bounded RSS-only maintenance while preserving
the last good data.
